# 원고 뽑기

영상 파일이나 링크(유튜브 등)를 넣으면 **한국어 음성을 텍스트로 받아쓰기**하고, 내용을 **2~5줄로 요약**해 주는 프로그램입니다. 음성 인식과 요약 모두 **내 컴퓨터에서(오프라인)** 처리합니다.

## 실행 방법

### 웹으로 쓰기 (링크로 접속) — 추천
**`원고뽑기_웹실행.bat` 더블클릭** → 브라우저가 열리고 아래 주소로 접속됩니다.

```
http://localhost:8010
```

같은 와이파이(사내 LAN)의 동료도 `http://<내PC IP>:8010` 으로 접속해 쓸 수 있어요.

### 데스크톱 창으로 쓰기
**`원고뽑기_실행.bat` 더블클릭** (또는 `python app.py`)

## 사용법

1. 영상/음성 파일을 **창에 끌어다 놓기(드래그&드롭)** 하거나, `파일 선택`, 또는 입력칸에 **유튜브 링크 붙여넣기**
2. (선택) **정확도**와 **요약 줄 수** 조정
3. `변환 시작` 클릭 → 잠시 후 **요약**과 **전체 원고**가 표시됩니다
4. `결과 저장(.txt)` 또는 복사 버튼으로 내보내기

## 유튜브 링크가 막힐 때 (봇 차단 / "Sign in to confirm you're not a bot")

최신 크롬·엣지는 쿠키를 암호화해서 프로그램이 자동으로 읽지 못합니다. 이럴 땐 **쿠키 파일**을 쓰면 확실합니다.

1. 크롬/엣지에 **`Get cookies.txt LOCALLY`** 확장프로그램 설치
2. **유튜브에 로그인한 상태**에서 유튜브 페이지를 열고, 그 확장으로 `cookies.txt` 내보내기
3. 저장한 `cookies.txt`를 **이 프로그램 폴더에 넣기** (자동 인식) — 또는 `쿠키 파일` 버튼으로 직접 지정
4. 다시 `변환 시작`

> 더 간단한 방법: 유튜브 영상을 직접 파일로 내려받아 창에 드래그&드롭 하면 쿠키가 필요 없습니다.

## 정확도(모델) 안내

| 모델 | 정확도 | 속도 | 최초 다운로드 |
|------|--------|------|----------------|
| tiny | 낮음 | 매우 빠름 | 약 75MB |
| base | 보통 | 빠름 | 약 145MB |
| **small** (기본) | 좋음 | 보통 | 약 484MB |
| medium | 매우 좋음 | 느림 | 약 1.5GB |
| large-v3 | 최고 | 매우 느림 | 약 3GB |

- 회의/인터뷰처럼 정확도가 중요하면 `medium` 추천
- **모델은 처음 한 번만 인터넷으로 내려받고**, 이후에는 오프라인으로 동작합니다

## 최초 설치(한 번만)

```bash
pip install -r requirements.txt
```

`ffmpeg`는 바탕화면에서 자동으로 찾습니다. (링크 다운로드 시 필요)

## 참고

- 지원 파일: mp4, mkv, mov, avi, webm, mp3, m4a, wav 등
- 영상이 길수록 인식 시간이 오래 걸립니다 (CPU 기준)
- 요약은 원문에서 핵심 문장을 뽑는 방식(추출 요약)입니다
