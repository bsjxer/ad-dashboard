# 경쟁사 광고 아카이빙 (Meta 광고 라이브러리)

경쟁사가 페이스북·인스타그램에 돌리는 광고를 **소재 파일까지 통째로 내 PC에 모아두고**,
로컬 웹 대시보드에서 브랜드·기간·문구로 검색·비교하는 프로그램입니다.

## 실행

**`경쟁사광고_실행.bat` 더블클릭** → 브라우저가 열립니다.

```
http://localhost:8011
```

## 최초 1회 준비

```bash
pip install playwright flask httpx
python -m playwright install chromium
python collect.py --login
```

`--login` 은 크롬 창을 띄워 페이스북 로그인만 하고 세션을 `browser_profile/` 에 저장합니다.

### 왜 로그인이 필요한가 (30건 문제)

광고 라이브러리는 **첫 화면 30건을 HTML 문서 안에 심어서** 보내주고,
그 아래로 스크롤할 때부터 별도 요청으로 더 받아옵니다.
그런데 **로그인하지 않은 상태에서는 이 스크롤 요청을 페이스북이 전부
`Rate limit exceeded` 로 거절**합니다. 그래서 검색 결과가 170개여도 30건에서 멈춥니다.

이 프로그램은 로그인 없이도 최대한 긁도록 **게재 시작일 구간을 쪼개서 여러 번
로드**합니다. 한 구간이 30건에 걸리면(= 잘렸다는 뜻) 그 구간을 절반으로 다시 나누고,
하루 단위까지 가도 걸리면 소재 유형(이미지/영상)으로 한 번 더 나눕니다.
로그인을 하면 스크롤 페이지네이션이 열려서 훨씬 빠르고 깊게 수집됩니다.

## 수집하기

대시보드 상단 **"새로 수집하기"** 에서 브랜드·키워드를 넣고 눌러도 되고, 터미널에서 직접 돌려도 됩니다.

```bash
python collect.py --brand 쿠팡 --keyword 쿠팡 --max 100
```

특정 페이지의 광고를 전부 받고 싶으면 (광고 라이브러리에서 광고주를 클릭하면 URL에 `view_all_page_id` 가 보입니다):

```bash
python collect.py --brand 어떤브랜드 --page-id 149885735024609 --max 200
```

경쟁사 여러 곳을 한 번에:

```bash
python collect.py --targets targets.json
```

`targets.json` 을 우리 경쟁사 목록으로 고쳐 두고 주기적으로 이 한 줄만 돌리면 됩니다.

### 주요 옵션

| 옵션 | 설명 |
|------|------|
| `--max 100` | 브랜드당 최대 수집 건수 |
| `--active-status active` | 진행 중인 광고만 |
| `--media-type video` | 영상 소재만 |
| `--country KR` | 광고 게재 국가 (기본 KR) |
| `--headless` | 브라우저 창 숨기고 수집 |
| `--pause 4` | 스크롤 간 대기 초 — rate limit 걸릴 때 늘리기 |
| `--since 2026-01-01` | 게재 시작일 하한 (기본: 2년 전) — 좁히면 훨씬 빠릅니다 |
| `--until 2026-06-30` | 게재 시작일 상한 (기본: 오늘) |
| `--no-media` | 이미지/영상 파일은 안 받고 텍스트 정보만 |

## 저장 형태

```
경쟁사광고아카이브/
  archive.db          SQLite (ads / media / runs 테이블)
  media/<브랜드>/      광고 이미지·영상 원본 파일
  collect.log         대시보드에서 실행한 수집 로그
```

광고 하나당 저장되는 정보: 광고 ID, 페이지명, 게재 시작·종료일, 진행 여부,
노출 플랫폼, 본문·제목·CTA, 랜딩 URL, 소재 파일, **처음 발견한 날짜(first_seen)**.

`first_seen` 이 있어서 **최근 7일 신규 광고**를 대시보드에서 바로 확인할 수 있습니다.
같은 광고를 다시 수집하면 중복 저장 없이 종료일·활성 여부만 갱신됩니다.

## 대시보드 기능

- 브랜드 / 진행여부 / 소재유형 / 게재 시작일 구간 / 문구 검색
- 카드 클릭 → 소재 전체·본문·CTA·랜딩 URL 상세
- 라이브러리 원본 링크 (검증용)
- 조건 그대로 **CSV 내보내기**

## API 로는 왜 안 되나

Meta 공식 Ad Library API(`ads_archive`)는 **정치·사회이슈 광고**만 제공하고,
전체 광고는 **EU 국가에 게재된 광고**만 개방되어 있습니다(DSA 의무).
한국에 게재된 상업 광고는 API 로 조회되지 않습니다.

직접 확인해 보려면 그래프 API 탐색기에서 토큰을 만들어:

```bash
python api_check.py --token EAAG...
```

KR/DE/IE 를 비교해서 실제 응답을 보여줍니다.
그래서 이 프로그램은 **공개 광고 라이브러리 페이지**가 내부적으로 받아오는 JSON 을
브라우저 안에서 가로채 구조화된 데이터로 저장하는 방식을 씁니다.

## 주기적 수집

`targets.json` 에 경쟁사를 채워 넣고, 아래 한 줄을 시작프로그램/래퍼로 매일 돌리면
신규 광고가 자동으로 쌓입니다.

```bash
python collect.py --targets targets.json --headless
```
